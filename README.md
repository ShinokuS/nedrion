# NEDRION — Последний огонь

Играбельный браузерный прототип: extraction ARPG с автоматическим боем, процедурным подземельем и камнями умений. Phaser 3.90 + Vite, интерфейс на русском языке.

## Запуск

Требуется Node.js 22.12+.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Также поддерживается `pnpm install` / `pnpm dev`; lockfile зафиксирован для pnpm.

```sh
npm test          # unit-тесты
npm run build    # production-сборка в dist/
npm run preview  # локальная проверка сборки
```

В dev-режиме открыть `http://127.0.0.1:5173/?smoke=1`, чтобы выполнить интеграционные сценарии в настоящей Phaser-сцене. Проверки используют изолированные игровые профили и восстанавливают исходное сохранение. Этот тестовый модуль исключается из production-сборки.

## Что реализовано

- Убежище с проводником, торговцем и тайником. NPC доступны через E рядом с ними; боковая панель предоставляет быстрый доступ.
- Связный данж из 12 комнат и коридоров. Генерация по seed, коллизии со стенами, мини-карта и отметки посещённых комнат.
- Волны скелетов и зомби с ростом здоровья, скорости и частоты появления. Навигация врагов использует поле расстояний по проходимой сетке.
- Автоматические огненные шары, стрелы, летящие разрезы и ледяное кольцо. Снаряды сталкиваются со стенами и врагами. Рывок на Space; кольцо можно назначить на Q.
- Выпадение и сбор опыта. При повышении уровня — выбор одного из трёх улучшений. Улучшения действуют только в текущем забеге.
- Предметы разного размера, рюкзак 8×5, тайник 10×7, сетки контейнеров. Drag-and-drop, проверка пересечений, перенос без дублирования.
- Поэтапный обыск: один предмет каждые 0,9 секунды. Бой продолжается при открытом инвентаре и обыске. Удаление открытого предмета не раскрывает следующий автоматически.
- Оружие (посох, меч, лук), доспехи, умения, поддержки, ключи и ценности. Четыре редкости с множителями характеристик и стоимости.
- Линейные сокеты: поддержка учитывается только непосредственно слева/справа от умения. Стрела требует лук, разрез — меч; огонь и кольцо универсальны. Поддержки снарядов не применяются к кольцу.
- Три независимых выхода: ключ из сундука; руны I → II → III; 35 убийств. У готового выхода нажмите E и стойте 3 секунды. Движение, урон или утрата условия отменяют эвакуацию.
- Через 3:30 начинается сужение безопасной области к стартовой комнате. За границей нарастает урон. Волны продолжаются бесконечно; одновременно не более 140 врагов.
- Успешная эвакуация сохраняет добычу. Смерть уничтожает рюкзак, экипировку и вставленные камни, сохраняя тайник и золото убежища.
- Покупка и продажа предметов. Бесплатный комплект доступен, когда оружия нет ни на персонаже, ни в рюкзаке, ни в тайнике. Бесплатные предметы не дают золота при продаже.
- Сохранения в localStorage. Перезагрузка/закрытие вкладки во время вылазки считается её потерей.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| E | NPC, обыск, руны, эвакуация |
| I | Снаряжение и рюкзак |
| Space | Рывок, перезарядка 4 секунды |
| Q | Назначенное ледяное кольцо, перезарядка 7 секунд |
| Escape | Закрыть окно / поставить игру на паузу |

Двойной щелчок по предмету в контейнере забирает его; в окне тайника перемещает между тайником и рюкзаком. Чтобы вставить камень, выберите его в рюкзаке и нажмите пустой сокет. Нажатие на установленный камень извлекает его, если хватает места.

## Архитектура

- `src/core.js`: предметы, сетки, транзакции перемещения, профили, связи камней, генерация и навигация. Не зависит от Phaser/DOM.
- `src/scene.js`: Phaser-сцена, исследование, бой, эффекты, волны, взаимодействия и эвакуация.
- `src/main.js`: HTML-интерфейс, окна инвентаря/торговца, операции с экипировкой, сохранения.
- `src/style.css`: оформление и адаптация интерфейса.
- `tests/core.test.js`: инварианты игровой модели и 100 seed генератора.
- `tests/browser-smoke.js`: интеграционные сценарии сцены и DOM.
- `public/assets/SOURCES.md`: происхождение выбранных ассетов.

## Границы прототипа

Одиночная игра для компьютера с клавиатурой. Сохранение локальное и привязано к адресу сайта; сервера, аккаунтов, облачного прогресса, мультиплеера и защиты от изменения сохранений нет. Не открывайте один профиль в нескольких вкладках одновременно. Звук, управление с телефона/геймпада, случайные аффиксы, большой каталог экипировки, боссов и биомов пока не добавлялись. Баланс предварительный.

Герой и NPC используют выбранные анимационные кадры Hero Siege, а не полный набор направленных анимаций. Полы и стены рисуются процедурно. Каркас карты и цели видны сразу, посещённые комнаты подсвечиваются — это упрощение навигации для первой проверки цикла игры.

Ассеты Hero Siege предоставлены пользователем для прототипа. Репозиторий не предоставляет лицензии на эти сторонние изображения. Их происхождение перечислено в `public/assets/SOURCES.md`.

2. Добавить генерацию аффиксов, типы базовых предметов, таблицы лута и более богатую систему связей камней.
3. Добавить новые биомы, события комнат, элитных врагов и более сложные условия выхода.
4. Ввести собственные/лицензированные ассеты, звук, направленные анимации и телеграфирование опасных атак.
5. При необходимости — серверный профиль, облачные сохранения и кооператив.
