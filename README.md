# NEDRION — Последний огонь

Браузерный extraction ARPG на Phaser 3.90. Автоматический бой, случайные катакомбы, добыча и эвакуация. Графика взята из предоставленного архива Hero Siege; интерфейс работает внутри canvas.

## Запуск

Node.js 22.12+: `npm install`, `npm run dev`. Открыть http://127.0.0.1:5173/.

`npm test` — тесты игровой модели. `npm run build` — сборка в dist. В dev-режиме адрес `/?smoke` запускает проверки настоящей Phaser-сцены: торговлю, координаты UI, взаимодействие через наведение и E, коллизии, прозрачность, стрелы, создание данжа, обыск, эвакуацию и смерть. Существующий профиль восстанавливается после проверки.

## Управление

- Навести мышь на объект — подсветить; подойти клавиатурой и нажать E. Хоткей появляется над объектом только рядом. Ходьбы по клику нет.
- WASD / стрелки — движение. E — объект под курсором в пределах досягаемости.
- I — инвентарь; Escape — закрыть окно / пауза; Space — рывок; Q — назначенное умение.
- Предметы можно перетаскивать или брать и класть последовательными кликами. ПКМ надевает / снимает экипировку; Shift + ЛКМ быстро переносит вещи между сетками.
- Покупка: перетащить товар из сетки продавца в рюкзак. Продажа: перенести предмет из рюкзака в окно продавца. Цена видна при наведении. Бесплатный комплект доступен, если оружия нет ни на герое, ни в рюкзаке, ни в тайнике.
- Камень из рюкзака перетащить в сокет надетого предмета. ПКМ по сокету извлекает камень. ЛКМ по установленному ледяному камню назначает его на Q. Линии соединяют соседние сокеты; поддержки влияют на соседние камни умений.

## Текущий прототип

- Оригинальные панели, предметные ячейки, кнопки и рамки экипировки. Секция талисманов удалена. Интерфейс имеет собственную камеру и единый масштаб по высоте окна; текст рисуется с повышенным разрешением. Герой по центру камеры мира; окружение закрывает края убежища.
- Симметричная раскладка: оружие, щит, броня, шлем, перчатки, обувь, пояс, два кольца и амулет. Рюкзак 12×5; прежние сохранения расширяются без удаления предметов.
- Тайник, сетка продавца, поисковые контейнеры, предметы на земле; переносы сохраняют вещи при нехватке места. Обыск поочерёдно открывает предметы с полосой прогресса. Мебель имеет коллизии и становится прозрачной, когда перекрывает героя.
- Карта 160×120 тайлов, до 28 комнат с нишами, ветвлениями и кольцевыми маршрутами. Оружейные, камеры, архивы, склепы и склады обставлены разными наборами мебели; более 60 хранилищ и отдельная добыча на земле. Туман войны ограничивает обзор стенами и сохраняет исследованные области.
- Разные типы противников, согласованные оригинальные наборы движения, атаки, покоя и смерти; оригинальные снаряды и опыт. Волны усиливаются со временем.
- Три выхода: ключ, руны, убийства. После 3:30 сужается безопасная зона. Успешный выход сохраняет добычу; смерть теряет рюкзак и экипировку, но сохраняет тайник.

## Код и ассеты

`src/core.js` — модель и генератор; `src/inventory.js` — операции с предметами; `src/scene.js` — бой и рейд; `src/presentation.js` — UI, сетки и сокеты; `src/world.js` — две камеры, оригинальные анимации, коллизии, прозрачность, тематическая расстановка и взаимодействия.

`public/assets/original/manifest.json` содержит точные исходные имена и размеры 933 кадров. Повторный импорт: `python scripts/import-assets.py D:/Temp/HERO_SIEGE` (нужен Pillow). Кадры сортируются по числовому индексу, чтобы варианты UI и анимации не перемешивались.

Это реконструкция на Phaser, а не исходный клиент Hero Siege или PoE. Герой использует цельные направленные анимации Armored Knight из архива. Скин героя пока фиксированный: замена его внешности по каждому предмету экипировки, полноценные аффиксы, звук, мультиплеер и мобильное управление пока не реализованы. Сохранения локальные. Ассеты предоставлены пользователем; происхождение остальных наборов описано в public/assets/SOURCES.md.
